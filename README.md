# Carga EV

PWA para iPhone alojable gratis en GitHub Pages.

## Publicar
1. Crea un repositorio nuevo en GitHub llamado `carga-ev`.
2. Sube TODOS los archivos de este ZIP a la raíz del repositorio.
3. En el repositorio entra en Settings > Pages.
4. En Build and deployment selecciona `Deploy from a branch`.
5. Branch: `main` y carpeta `/ (root)`. Pulsa Save.
6. Espera uno o dos minutos. GitHub mostrará la dirección publicada.

## Instalar en iPhone
Abre la dirección publicada con Safari > botón Compartir > Añadir a pantalla de inicio.

La aplicación dispone de caché offline mediante Service Worker.
